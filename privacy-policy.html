Política de Privacidade

Última atualização: Abril de 2026

O Notinha respeita a sua privacidade. Esta política descreve quais dados coletamos, como os utilizamos e quais são os seus direitos de acordo com a Lei Geral de Proteção de Dados (LGPD).

Dados que coletamos

Fornecidos por você

  • Fotos de recibos — capturadas pela câmera ou selecionadas da galeria para digitalização via OCR.
  • Dados de recibos — valor, estabelecimento, categoria, data, forma de pagamento e observações inseridos ou editados manualmente.
  • Conta Google — se você optar por fazer login, coletamos nome, e-mail e foto de perfil fornecidos pelo Google Sign-In.

Coletados automaticamente

  • Dados de falha — relatórios de crash anônimos para corrigir problemas técnicos.

Dados que NÃO coletamos

  • Não coletamos dados bancários, senhas ou números de cartão de crédito.
  • Não coletamos dados de localização (GPS).
  • Não coletamos contatos ou histórico de ligações.
  • Não realizamos coleta de dados de uso para fins analíticos.

Como usamos seus dados

  • Processamento de recibos (OCR) — as fotos são processadas localmente no dispositivo usando o Google ML Kit. Nenhuma imagem é enviada a servidores externos no processamento OCR básico.
  • Análise por IAPremium — assinantes Premium podem ter o texto já extraído do recibo (nunca a imagem) enviado à OpenAI via Supabase Edge Functions para melhorar a precisão da categorização automática.
  • Backup na nuvemPremium — se ativado, seus recibos são sincronizados com servidores seguros (Supabase — PostgreSQL + Storage) para backup e acesso em múltiplos dispositivos.
  • Correção de problemas — relatórios de crash anônimos ajudam a identificar e corrigir falhas técnicas.

Armazenamento e segurança

  • Dados locais — por padrão, todos os seus dados ficam armazenados exclusivamente no seu dispositivo (banco de dados Room local).
  • Backup na nuvem (Premium) — armazenado nos servidores do Supabase com criptografia em trânsito (TLS/SSL) e em repouso. O Supabase atua como processador de dados sob nossas instruções.
  • IA (Premium) — o texto processado pela OpenAI não é utilizado para treinar modelos, de acordo com a política de uso da API da OpenAI.

Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins de marketing ou publicidade.

  • Google Play Billing — o Google recebe informações de pagamento diretamente para processar assinaturas Premium. Não temos acesso ao seu cartão ou dados bancários.
  • Supabase — infraestrutura de armazenamento em nuvem e execução das funções de IA (apenas usuários Premium com backup ativado).
  • OpenAI — processa o texto extraído dos recibos para categorização automática (apenas usuários Premium). Não recebe imagens nem dados pessoais identificáveis.
  • Obrigação legal — podemos divulgar dados se exigido por lei ou ordem judicial.

Permissões do aplicativo

📷 Câmera Fotografar recibos e notas fiscais.
🖼️ Fotos / Armazenamento Acessar fotos de recibos já salvas na galeria.
🌐 Internet Backup na nuvem, IA e verificação de assinatura Premium.

Seus direitos (LGPD)

👁️ Acessar Dados visíveis diretamente no app.
📤 Exportar Exporte seus dados como planilha XLSX.
🗑️ Excluir Configurações → Limpar dados.
✏️ Corrigir Solicite correção de dados imprecisos.
📦 Portabilidade Solicite seus dados em formato estruturado.
🚫 Cancelar conta Solicite exclusão da conta e dados na nuvem por e-mail.

Retenção de dados

  • Dados locais — permanecem no dispositivo até você excluir o app ou limpar os dados manualmente.
  • Dados na nuvem (Premium) — mantidos enquanto sua conta estiver ativa. Após exclusão da conta, removidos em até 30 dias.

Menores de idade

O Notinha não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente dados de menores. Se tomarmos conhecimento de que coletamos dados de uma criança, os excluiremos imediatamente.

Alterações nesta política

Podemos atualizar esta política periodicamente. Notificaremos você sobre mudanças significativas por meio de uma atualização no aplicativo. A data de última atualização será sempre indicada no topo desta página.
